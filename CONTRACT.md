BOUNDARIES: protobuf/gRPC between services; JSON inside every `payload` bytes field; JSON over WebSocket to the web app; JSON on Redpanda. All JSON keys snake_case, all timestamps int64 milliseconds since epoch (UTC), lat/lon float64 degrees (WGS84), h3_cell uint64 at resolution 9, ids are UUID strings, hlc is int64 (physical ms << 16 | counter).
PROTO: package aegismesh.v1, files in proto/aegismesh/v1. Every request/reply message has `string tenant_id = 1; bytes payload = 2;` (generated; do not edit). `payload` is UTF-8 JSON of the shape listed below for that RPC.
GO STUBS: gen/go is a Go module named github.com/aegismesh/aegismesh/gen; generated package dir gen/go/aegismeshv1 (import github.com/aegismesh/aegismesh/gen/aegismeshv1, package aegismeshv1). Services use `replace github.com/aegismesh/aegismesh/gen => ../../gen/go`.
PY STUBS: gen/py/aegismesh/v1/*_pb2.py and *_pb2_grpc.py; services add gen/py to sys.path in conftest.py.
TENANCY: tenant_id comes from the JWT claim `tenant_id`, never from the payload; a call without it is refused with gRPC code UNAUTHENTICATED.
ERRORS: gRPC status codes only (INVALID_ARGUMENT, NOT_FOUND, FAILED_PRECONDITION for a locked unit, ALREADY_EXISTS for a duplicate id); message text is plain, no stack traces.
EVENT (event_store row and Redpanda value): {"sequence_id":1,"aggregate_id":"<uuid>","event_type":"IncidentReported","payload":{...},"actor_id":"<uuid>","prev_hash":"<64 hex>","entry_hash":"<64 hex>","ts":1700000000000}. event_type is one of IncidentReported, UnitDispatched, RoadBlocked, HazardPolygonAdded. entry_hash = sha256(prev_hash + canonical_json(rest)); the first prev_hash is 64 zeros.
